# ندى — Nada Search Homepage

واجهة عربية خفيفة ومتجاوبة مستوحاة من تصميم صفحات البحث المعروفة. البحث يعمل عبر Google Search، لذلك النتائج تُعرض على Google وليس داخل موقع ندى نفسه.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub باسم `nada-search`.
2. ارفع ملف `index.html` إلى جذر المستودع (ويمكن رفع `README.md` أيضًا).
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages، غالبًا بالشكل `https://USERNAME.github.io/nada-search/`.

لا تحتاج إلى خادم أو قاعدة بيانات. لتغيير اسم الموقع أو الألوان، عدّل `index.html` ثم ارفع التغييرات إلى المستودع.
